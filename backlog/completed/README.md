## 🔄 Proceso para Registrar un Feature Completado

Cuando un desarrollador finaliza un requerimiento y cumple con la *Definition of Done*:
1. Mueve el archivo correspondiente desde `backlog/pending/FEAT-XXX.md` a esta carpeta (`backlog/completed/FEAT-XXX.md`).
2. Actualiza los metadatos del archivo (`Estado: Completado`, `Fecha de Finalización: AAAA-MM-DD`).
3. Agrega la fila correspondiente en la tabla de este archivo bajo la versión entregada.
4. Elimina la fila del feature de [backlog/pending/README.md](../pending/README.md).
5. Documenta los cambios en el archivo raíz [CHANGELOG.md](../../CHANGELOG.md).
